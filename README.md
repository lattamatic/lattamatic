# Sandeep Chituprolu

Product Manager in Paris. I build working versions of the products I think about, because a prototype answers questions a spec cannot.

Most of what is here started as a real problem at home or at work, went through a small product process (who is it for, what does success look like, what are we not doing) and ended as something people use.

## How I work

- **Start from the user's job, not the feature list.** Each project above names who it is for and what it deliberately leaves out.
- **Prototype early.** A no-code or throwaway version first, to test the habit before investing in the build.
- **Design the failure state.** When something cannot be perfect, make the error visible and recoverable.
- **Build with AI assistants, review like a tech lead.** Changes arrive as pull requests with their test status; I decide what ships.
